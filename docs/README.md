## 维护时从哪里查

- 普通用户先从 Wiki 的[开始阅读](wiki/V1-01-开始阅读.md)进入，按准备、安装、配置、付款核对依次完成。
- 接入开发以[易支付 V1 接口参考](wiki/V1-16-易支付V1接口参考.md)为准，插件开发以[插件接口](wiki/V1-23-支付插件开发.md)、[字段规则](wiki/V1-24-config-schema字段规则.md)和[主动采集](wiki/V1-25-主动采集与会话协作.md)为准。
- 系统内部职责、时间和事务规则查[开发环境与目录结构](wiki/V1-21-开发环境与目录结构.md)、[支付数据约定](wiki/V1-22-支付链路与数据约定.md)及[业务边界](wiki/V1-32-业务边界与回归验收.md)。
- 版本更新和文档组织查[维护约定](wiki/V1-28-版本更新与文档维护.md)，Wiki 检查、导出及本站接口文档生成查[工具说明](wiki/tools/README.md)。
- 公共版与本地插件版采用同一 Git 仓库的两个工作树；公共代码和共同文档先在 `v1` 维护并提交，再单向合入本地插件分支，维护规则见[双工作树维护约定](wiki/V1-28-版本更新与文档维护.md#公共版与本地插件版的开发维护)，具体命令和交付文件清单保留在源码的 `docs/paid-plugins/README.md`。

本站 `/docs/` 只用于易支付 V1 接入，由接口参考生成；不要直接修改生成页面。用户操作的完整解决办法保留在所属专题，其他页面用必要的摘要和直达链接引用，不在每篇文末追加同一条变更记录。

本地接手时读取 AGENTS.md 与 `docs/implementation-plan.md` 顶部进度。部署和验证记录只说明当时的环境与范围，不能替代对当前目标站点的实际核对；本地交接文件不作为公开使用教程。
