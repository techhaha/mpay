# 前端组件与主题

页面由 ThinkPHP 模板渲染，主要数据通过同源 API 获取；Layui 资源本地交付，当前版本 2.13.9。不修改框架组件源码，不再引入另一套表格、弹窗或日期控件。

## 组件与公共入口

| 需求 | 官方组件 / 公共适配 |
| --- | --- |
| 表格、分页、条数 | table → `MpayAdmin.table`；使用 page/limit/limits，分页在右下角 |
| 表单、选择、开关 | form → `MpayForm` / `MpayAdmin.render`；schema 与原生服务端 Validate 合作 |
| 对话框、抽屉、帮助 | layer → `MpayAdmin.open/form/confirm`；遮罩、动画、关闭由组件处理 |
| 日期与时间 | laydate → 公共日期入口；保留官方白色面板，不转浏览器时区 |
| 标签页 | tabs；切换后通过官方事件调整表格 |
| 操作菜单 | dropdown；账户、更多操作统一使用 |
| 上传 | upload；格式/大小校验后通过 `MpayHttp` 发送同源请求 |
| 状态、图标、分区 | badge、icon、card、collapse；品牌素材独立保持比例 |

业务向导、二维码绘制、请求合同及支付状态轮询属于应用职责，不需要为了“全用组件”再包装空转发框架。客户端不生成识别金额，不决定交易是否成功。

## 主题与素材

`theme.css` 定义公共颜色；`app.css` 管基础排版，`admin-layout.css` 管侧栏/顶栏，`admin.css` 管后台业务展示，安装和收银台各有局部样式。

后台使用深蓝灰侧栏、青色主按钮白字、灰白内容区；蓝色用于查看链接，绿色/橙色/红色/灰色区分状态。模板和页面样式不另建独立色板。深色侧栏用浅色字标，其他浅色页面用标准 MPAY 字标。

小支付图标用于列表、卡片与选择项，带文字的完整标识用于收银台品牌区。二维码本身不叠 Logo。云闪付当前识别图形为项目绘制素材，不宣称官方商标图稿。

## 新增页面的约定

使用显式路由、公共请求和异常处理；输出转义，读写权限与 CSRF 在服务端校验。表单保留处理中锁和未保存保护，不让超时响应诱导重复提交。

主操作保持一个视觉重点，细节用详情页签或帮助提示展开。通道参数说明只由插件定义，空 description/help 不显示系统额外说明。列表状态带文字，不只靠颜色表达。

修改后检查空/错误/禁用/焦点状态、重复打开弹层、桌面和手机布局；资源更新同步版本参数。界面测试与真实支付验证分别记录。
