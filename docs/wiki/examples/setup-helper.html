MPAY 安装命令生成助手

填写一次路径，生成可以复制的完整命令。此页面可以下载后离线打开，不连接服务器，不执行命令，也不需要填写密码或 KEY。

1. 从你的服务器复制这三项

只填写域名，例如 pay.example.com；不带 https:// 和页面路径。 包含 think、app、public 等文件的目录，不要填到 public 里面。 请确认这是你选择的 PHP 8.2 或更高版本。示例路径中的 82 不是强制要求。

2. 按教程复制使用

下面的命令包含你填写的真实路径。先完成网页安装，再添加后台任务。不要把整页所有命令一起粘贴执行。

3. 保存一份操作清单

清单仅包含域名和路径，不包含凭证。重新换目录或 PHP 后，请重新生成。

可选：生成手机通知密钥

配置手机监听时使用。生成后，把同一个值分别复制到 MPAY 通道的“通知密钥”和转发工具的 Secret。不要把它当作应用 KEY 或管理员密码。

使用浏览器安全随机数生成，只保留在当前页面，不上传、不写入命令清单；刷新后不保留。已有通道不要随意重新生成替换，修改时要同步通知工具。
