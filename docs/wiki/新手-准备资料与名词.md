# 安装前，先准备这些资料

这篇适合第一次使用 MPAY 的用户。你不需要会写 PHP，也不需要先学接口签名。先分清两个网站，并准备安装要用的信息。

## 1. 分清 MPAY 与业务网站

假设你有一个卖商品的网站，还准备安装 MPAY：

业务网站应已有易支付 V1 接入模块，或者由开发者完成对接。MPAY 不包含商城、商品管理或发货系统；只有 MPAY 时，可以先配置通道，购买订单仍需从业务网站发起。

| 例子 | 是什么 | 你会在哪里操作 |
| --- | --- | --- |
| `shop.example.com` | 你的商城，也叫业务网站 | 配置易支付、查看购买订单 |
| `pay.example.com` | 你的 MPAY 站点 | 配置收款通道、查看到账与商户通知 |

买家在商城购买商品，进入 MPAY 收银台付款。MPAY 核对到账后，把结果通知商城，商城再完成自己的订单处理。

本文中的 example.com 是说明用的域名，不能直接作为你的站点使用。后续所有地址，都从你自己的网站设置中复制。

## 2. 把安装资料记在自己的私有记录里

| 资料 | 从哪里取得 | 后面用在哪里 |
| --- | --- | --- |
| 服务器面板地址、登录账号 | 你的服务器或面板管理者 | 创建网站、数据库、配置后台任务 |
| MPAY 网站域名 | 你准备给 MPAY 使用的域名 | 网站设置、浏览器访问 MPAY |
| 业务网站域名 | 复制商城等业务网站的域名部分 | MPAY 应用的“允许的回调域名” |
| MPAY 程序目录 | 网站创建后，在面板的网站目录设置中复制 | 网站运行目录、两个后台任务 |
| PHP 命令行路径 | 面板的 PHP 安装目录或管理员提供的完整路径 | 运行后台任务 |
| 数据库地址与端口 | 创建数据库的位置；本机数据库和远程数据库不同 | 网页安装第二步 |
| 数据库名、用户名、密码 | 创建专用空数据库时得到 | 网页安装第二步 |
| 收款二维码 | 实际收款账号中保存的收款码图片 | 新增通道的插件参数 |

数据库密码、管理员密码和应用 KEY 不要写在公开文档或截图里。后面的截图只展示填写位置。

## 3. 核对你拿到的是哪个版本

这套教程对应 MPAY V1 的 ThinkPHP 重构版。旧版发行包、V2 和本版不能混着安装。

解压程序后，应在同一级目录看到：

```text
app
config
database
public
route
view
composer.json
composer.lock
think
```

有些压缩包外面还套了一层文件夹。**包含 think 文件的这一层才是程序目录**，它下面的 public 才是网站运行目录。

如果交付包明确已包含生产依赖，通常还能看到 vendor 目录。源码不含依赖时，需要按照[安装指南](V1-03-安装与环境要求.md)安装；不要从别的版本复制 vendor 混用。

当前重构版尚未作为正式发行包发布。打开 [Gitee v1 源码](https://gitee.com/technical-laohu/mpay/tree/v1)或 [GitHub v1 源码](https://github.com/techhaha/mpay/tree/v1)，确认分支为 `v1` 后使用该页面的 ZIP 下载入口。GitHub 页面通过“Code → Download ZIP”下载；这份是源码压缩包，运行依赖仍按[依赖准备](V1-03-安装与环境要求.md#源码部署的依赖准备)安装，不要使用旧版 Releases 包套用本文。

## 4. 选择与你资料相符的收款方式

| 你现在有什么 | 先看哪一篇 |
| --- | --- |
| 微信收款码、能接收到账通知的安卓手机 | [微信手机监听](V1-11-微信手机与PC监听.md) |
| 支付宝收款码、能接收到账通知的安卓手机 | [支付宝手机监听](V1-12-支付宝手机监听.md) |
| 具备账单查询权限的支付宝应用和账号 | [支付宝账单收款](V1-13-支付宝账单收款.md) |
| 收钱吧账号和对应收款码牌 | [收钱吧码牌收款](V1-14-收钱吧码牌收款.md) |

只有二维码，还不足以让 MPAY 知道是否到账。手机通知或账单查询负责把到账信息提供给 MPAY。

## 5. 后台这几个名字分别指什么

| 页面中的名字 | 你可以这样理解 |
| --- | --- |
| 应用 | 为你的一个业务网站建立的接入资料 |
| PID | 这份接入资料的编号，复制给业务网站 |
| KEY | MPAY 与该网站核对请求的密钥，必须和 PID 配套 |
| 支付方式 | 微信支付、支付宝等分类 |
| 插件 | 负责解释平台收款消息的程序 |
| 通道 | 一套实际使用的收款设置，例如“我的支付宝收款” |
| 默认轮询组 | 系统已准备好的通道集合；新通道会自动加入 |
| 商户通知 | MPAY 发给你的业务网站的付款结果，不是手机发给 MPAY 的消息 |

## 6. 复制地址和密钥时，按用途区分

| 内容 | 从哪里复制 | 粘贴到哪里 |
| --- | --- | --- |
| MPAY 网关、PID、应用 KEY | 应用详情的“接入信息”“凭证管理” | 业务网站的易支付设置 |
| 通道通知地址 | 收款配置中当前通道的“查看 → 接入信息” | 手机转发工具的 Server/Webhook |
| 通知密钥 | 为当前手机通道生成并保存的值 | 同时填入该通道与手机工具的 Secret |
| 允许的通知及回跳域名 | 业务网站使用的通知、返回地址中的域名 | MPAY 的应用编辑表单 |

例如 `https://shop.example.com/pay/notify` 的域名部分是 `shop.example.com`。`www.shop.example.com` 是另一个域名；业务网站实际用哪个就填写哪个，多个域名每行一项。

第一次使用不需要创建自定义轮询组，也不需要调整权重。先沿用默认收款，把一笔订单完整跑通。

**下一步：** 尚未建站时先做[宝塔建站准备](新手-宝塔建站准备.md)；网站已经准备好则直接[网页安装](V1-03-安装与环境要求.md)。
