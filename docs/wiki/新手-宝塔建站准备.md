# 在宝塔中准备 MPAY 网站和空数据库

这篇从“已经能登录宝塔面板”开始。宝塔管理服务器；MPAY 管理收款；商城负责卖商品。这三个登录入口及密码分别保存。

本文只说明 MPAY 需要的配置。面板按钮位置随版本变化，相关入口以宝塔官方文档为准；下面的 MPAY 安装截图见[网页安装指南](V1-03-安装与环境要求.md)。

## 1. 先取得对应的完整程序

本教程对应 ThinkPHP 重构版。按[取得 v1 源码](新手-准备资料与名词.md#3-核对你拿到的是哪个版本)下载后，在电脑上检查里面是否有 think、composer.json、composer.lock、app 和 public。旧版程序包不能用于这套教程。

这是开发版手册，不代表已经有通过正式发布验收的安装包。不要把旧版下载页的“最新版”自动当成当前重构版。

## 2. 创建独立网站

进入宝塔“网站 → 添加站点”，填入准备用于 MPAY 的域名，选择满足[环境要求](V1-03-安装与环境要求.md#环境要求)的 PHP，保存后记录网站目录。具体界面见[宝塔创建站点说明](https://docs.bt.cn/getting-started/create-web/)。

例如你的商城是 shop.example.com，MPAY 可以单独使用 pay.example.com。不要把商城程序解压目录选成 MPAY 的目录。

**完成检查：** 网站列表出现 MPAY 的域名；浏览器能打开这个域名的默认页面。暂时打不开时，先检查域名解析及网站端口，尚未进入 MPAY 安装阶段。

## 3. 上传并解压程序

1. 从 MPAY 网站对应行进入它的文件目录。
2. 上传程序压缩包，解压到这个站点的独立目录。
3. 找到 think 文件。它应与 app、config、public 等目录在同一级。
4. 复制这一层的完整路径，保存为“程序目录”。如果压缩包套了一层文件夹，要以实际包含 think 的那层为准。
5. 检查是否包含与本版配套的完整 vendor 依赖。仓库源码没有依赖时，按[源码部署的依赖准备](V1-03-安装与环境要求.md#源码部署的依赖准备)安装，再继续网页安装。

不要把多个版本的文件叠加解压到一起，也不要从另一套程序复制 vendor。

## 4. 把运行目录指向 public

打开网站设置的“网站目录”，将“运行目录”选择为 public，保存。网站目录是程序所在位置，运行目录是允许浏览器访问的位置；MPAY 必须从 public 进入。入口说明见[宝塔网站目录文档](https://docs.bt.cn/user-guide/site/php/site-config/website-directory/)。

例如程序目录是 `/www/wwwroot/pay.example.com`，运行目录的完整路径应是：

```text
/www/wwwroot/pay.example.com/public
```

这是路径示例。实际使用时从面板文件管理器复制本站的程序目录；网站运行目录选择它下面的 public。

接着按[部署指南](V1-18-部署与后台任务.md#web-服务器)配置网站路由。尤其要把 submit.php、mapi.php、api.php 交给 index.php；它们不是需要另行上传的 PHP 文件。现有网站的证书、PHP-FPM 地址及其他设置要与本机一致，不能把示例配置中的占位路径原样覆盖进去。

下载的 Nginx/Apache 文件是完整站点配置模板，**不要整份粘贴进宝塔“伪静态”输入框**。不熟悉 Web 服务器配置时，请让部署人员按模板完成本站配置，再由你继续网页安装；不要直接覆盖面板生成的其他站点或 PHP 配置。

## 5. 创建空数据库并保存连接资料

进入“数据库 → MySQL → 添加数据库”，新建一个仅用于 MPAY 的空库，字符集选择 utf8mb4。保存数据库名、用户名、密码、地址和端口。同机数据库使用本地访问权限；远程数据库只授权网站服务器需要的来源。入口及字段见[宝塔添加 MySQL 数据库说明](https://docs.bt.cn/user-guide/database/mysql/add)。

| 你的部署情况 | 安装页中的数据库地址 |
| --- | --- |
| 网站与数据库在同一台服务器 | 通常为 127.0.0.1；端口以数据库配置为准 |
| 网站与数据库在不同服务器 | 数据库服务器的实际地址；同时核对该库的连接授权 |

若建站时已经创建了专用空库，就使用那份资料，不必再建一次。不要选商城、博客或其他应用正在使用的库。

## 6. 配置 HTTPS，再进入安装

在站点 SSL 设置中配置与 MPAY 域名相符的证书，先确认 HTTPS 能正常打开，再设置强制 HTTPS。证书申请前需要域名正确解析、相应端口可访问，见[宝塔新手指南的 HTTPS 部分](https://docs.bt.cn/landing/getting-started/)。

在自己的 MPAY 地址后加 `/install`，继续[网页安装四步](V1-03-安装与环境要求.md)。安装页要求输入的是数据库连接资料，随后设置的是 MPAY 管理员密码，均不是宝塔面板密码。

安装完成后再按[后台任务指南](V1-18-部署与后台任务.md#用进程守护工具添加任务)添加两个任务。至此准备工作才完整，能打开网页并不代表商户通知已经在后台运行。
